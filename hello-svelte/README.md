# Svelte from Scratch

A progressive path through Svelte: components, reactivity, and stores
compiled away rather than run through a virtual DOM.

## Planned lessons

| File | Concept |
| --- | --- |
| `01-hello-world` | A first `.svelte` component |
| `02-components-and-props` | Props, component composition |
| `03-reactivity` | Reactive declarations (`$:`), events |
| `04-stores` | Writable/derived stores |
| `05-routing` | Client-side routing |

Not started yet — lessons will be added as numbered, self-contained files
following the pattern in `../hello-react`.
