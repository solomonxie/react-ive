# HTMX from Scratch

A progressive path through HTMX: driving the DOM with HTML attributes and
server responses instead of client-side JavaScript.

## Planned lessons

| File | Concept |
| --- | --- |
| `01-hello-world` | Loading HTMX, a first `hx-get` swap |
| `02-triggers-and-targets` | `hx-trigger`, `hx-target`, `hx-swap` |
| `03-forms` | `hx-post`, form submission, validation responses |
| `04-indicators-and-polling` | Loading indicators, `hx-trigger="every ..."` |
| `05-out-of-band-swaps` | `hx-swap-oob` for multi-region updates |

Not started yet — lessons will be added as numbered, self-contained files
following the pattern in `../hello-react`.
