# Tailwind CSS from Scratch

A progressive path through Tailwind: utility classes, responsive design,
and theming without hand-written CSS.

## Planned lessons

| File | Concept |
| --- | --- |
| `01-hello-world` | Setup, first utility classes |
| `02-layout` | Flexbox/grid utilities |
| `03-responsive` | Breakpoints, responsive variants |
| `04-states` | Hover/focus/dark-mode variants |
| `05-theming` | Custom theme, `@apply`, component classes |

Not started yet — lessons will be added as numbered, self-contained files
following the pattern in `../hello-react`.
