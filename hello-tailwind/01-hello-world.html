Hello, Tailwind!

This page has no custom CSS. Every visual choice — the font size, the spacing, the color of each element — comes from utility classes applied directly in the HTML.

A few basic utilities

p-4 adds padding, rounded-lg rounds the corners, and border draws a 1px border.

bg-sky-100 and text-sky-900 set background and text color from Tailwind's default color palette.

Utility classes read left to right roughly in the order the browser applies them: layout, box model, then color.

Compiled with the Tailwind CLI — no build step beyond npm run build.
