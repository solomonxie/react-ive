# TypeScript + Angular: a progressive learning path

A single Angular CLI project using standalone components (no NgModules). Each
numbered file is a complete, self-contained lesson — it contains everything
the previous step taught, plus one new concept, with its template and styles
inline in the component decorator.

These files were hand-authored to match Angular CLI's own conventions rather
than generated by `ng new`, so the first `npm install` needs to succeed
against the real Angular packages listed in `package.json`.

## Setup

```sh
cd hello-angular
npm install
npm run dev
```

## How to run a lesson

The app has one stable entry point, `AppComponent`, which reads `?lesson=NN`
from the URL and renders the matching lesson component. Pass the lesson
number to the runner:

```sh
npm run lesson -- 01
npm run lesson -- 02
npm run lesson -- 05
```

The command starts `ng serve` and opens the selected lesson. If you omit the
number, lesson 01 is used. You can also run `npm run dev` to start lesson 01.

## Lessons

| File | Concept | What's new |
| --- | --- | --- |
| `01-hello-world.ts` | Standalone components | Smallest possible component, with an inline template |
| `02-components-and-inputs.ts` | Inputs & outputs | Splits the greeting into a reusable `<app-greeting>` using signal-based `input()`/`output()` |
| `03-state-and-events.ts` | Signals & events | `signal()`/`computed()` for a controlled input and a click counter |
| `04-services-and-di.ts` | Services & DI | An injectable `UserService` wrapping `HttpClient`, consumed via `inject()` |
| `05-routing.ts` | Routing | Angular Router with static routes and a dynamic `/user/:id` route, owned by the lesson itself |

## Layout

```
hello-angular/
  angular.json          # CLI workspace config (esbuild application builder)
  src/
    index.html          # fixed HTML shell
    main.ts              # bootstraps AppComponent
    styles.css           # global reset/base styles
    app/
      app.config.ts      # ApplicationConfig: HttpClient, Router providers
      app.component.ts   # reads ?lesson=NN, renders the matching lesson
      lessons/
        01-hello-world.ts
        ...
        05-routing.ts
  scripts/run-lesson.mjs
```
